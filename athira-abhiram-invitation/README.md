# Athira & Abhiram wedding invitation

This is a standalone static website. Open `index.html` to preview it, or upload the whole `athira-abhiram-invitation` folder to any static website host. Keep the `assets` folder next to the HTML file.

## Editing

- Change the names, date, invitation message, venue, map URL, and page text in `index.html`.
- Change the countdown date or YouTube video ID in the `WEDDING` object at the top of `script.js`.
- Replace the four JPEG files in `assets` to change the portraits and gallery. Keep the same filenames, or update the image paths in `index.html` and `style.css`.
- Adjust colors, typography, spacing, and animation in `style.css`.

The cover tap starts the supplied YouTube track where browser playback allows it; the music button can pause or resume it. A hosted URL is needed for WhatsApp to fetch the Open Graph preview image and description.
